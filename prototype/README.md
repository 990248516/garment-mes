# 云裁 MES 可点击原型

这是服装扎包生产管理系统的静态交互原型，不需要安装依赖或连接数据库。

## 启动

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory /Users/ross/.kiro/crew/workspace/prototype
```

然后访问：<http://127.0.0.1:4173/>

也可以直接打开指定演示场景：

- 管理后台：<http://127.0.0.1:4173/>
- 工人扫码首页：<http://127.0.0.1:4173/#worker>
- 已识别扎包页面：<http://127.0.0.1:4173/#bundle>

## 推荐演示路径

### 管理端

1. 查看“生产总览”的产量、工序流量和风险提醒；
2. 进入“生产订单”，搜索订单并打开订单详情；
3. 进入“裁床扎包”，选择扎包并打开打印预览；
4. 进入“员工工种”，为张三编辑多个工种；
5. 进入“计件工资”，查看单价、数量和金额状态。

### 工人端

1. 点击右上角“进入工人端”；
2. 点击“模拟扫码”；
3. 等待识别 `10605-2`，点击“查看扎包”；
4. 查看当前允许工序、技能等级、单价和预计收入；
5. 点击“开始上袖”，再点击“完成上袖报工”；
6. 校验投入、良品、次品和短缺数量并确认；
7. 在“我的计件”查看新增加的收入明细。

## 原型范围

- 示例数据仅保存在当前页面内，刷新后重置；
- 二维码图案仅用于视觉演示，不可实际扫码；
- 打印按钮只模拟发送任务，不访问真实打印机；
- 原型用于验证信息架构、业务流程和交互，不包含真实认证、API 或数据库。
